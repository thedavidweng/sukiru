Sukiru

Skill libraries, sorted out.

Sukiru is a fast, tiny, native macOS app that checks and repairs your coding agents' skill libraries. It works through the official npx skills and gh skill installers and never keeps a ledger of its own.

Download for Mac Learn more

Free and open source · Requires macOS 14 Sonoma or later on Apple silicon

Every problem, in plain language.

Stale lock records, broken links, diverging copies, and skills claimed by both installers.

Two official installers write into the same agent directories, and neither reads the other's records. Sukiru reads both, compares them with what is on disk, and explains what went wrong and why. Healthy layouts and standing notices fold into Notes.

See the collision experiments

One skill. One owner.

Each fix goes to the installer that owns the skill.

There is no global backend setting. A skill installed with npx skills is repaired with npx skills; a skill installed with gh skill is repaired with gh skill. Sukiru never writes installer records itself.

npx skills update find-skills -g -y gh skill update pdf --dir ~/.claude/skills

Why Sukiru keeps no ledger

Know where every skill lives.

Owner, provenance, pinned ref, and placement across agents.

See which installer owns each skill and where it is linked or copied. Switch a skill between link and copy mode, find sources for hand-copied skills, and bring them under an installer.

Check. Fix. Roll back.

One-Click Fixes

Fix one problem or Fix All. Each fix becomes one batch that you confirm once, with the exact commands one click away.

Safe by Construction

Every batch runs as snapshot, execute, diff. Roll back with one click. The last 10 snapshots are kept.

Search and Install

Search skills.sh and gh skill search, preview SKILL.md, and install with the installer you choose.

Works Without the CLIs

With neither Node.js nor gh installed, Sukiru is still a complete read-only health checker.

Native

Pure Swift with system controls only. Follows your appearance and accessibility settings. In English and Simplified Chinese.

Local & Private

No accounts, analytics, or telemetry. No background activity. Snapshots stay on your Mac.

Get Sukiru.

Install with Homebrew or download the DMG and move Sukiru to Applications. Node.js and the GitHub CLI are optional; install them to make changes.

brew install --cask thedavidweng/tap/sukiru

Download the DMG View on GitHub

Releases are ad-hoc signed. If Gatekeeper blocks launch, open System Settings › Privacy & Security and click Open Anyway.
