Agent logo artwork

The agent logos in AgentIcons.xcassets identify compatible tools. Product names
and brand marks remain the property of their respective owners.

Amp, Antigravity, Claude Code, Codex, Cursor, Droid, Gemini CLI, GitHub
Copilot, Hermes Agent, OpenClaw, OpenCode, Pi, and Trae were converted from
Kitter's provider SVGs at commit 7de9372a8b691c8dffed6e9102d2c1c53b0e46b2:
https://github.com/what1f/kitter/tree/7de9372a8b691c8dffed6e9102d2c1c53b0e46b2/assets/icons
Kitter attributes these provider icons to Lobe Icons under MIT.
Copyright (c) 2023 LobeHub.

CodeBuddy, Command Code, Devin, Goose, Junie, OpenHands, Qoder, Qwen Code,
Replit, and Zencoder were converted from the monochrome SVGs of
@lobehub/icons-static-svg 1.95.1 (Lobe Icons, MIT, Copyright (c) 2023 LobeHub).

Augment, Cline, Kilo Code, Kimi Code CLI, Kiro CLI, Mistral Vibe, Roo Code,
Warp, Windsurf, and Zed were converted from aghub's agent SVGs at commit
61a7ee799a035cd5eb0ccae6515b9d151984ec52:
https://github.com/AkaraChen/aghub/tree/61a7ee799a035cd5eb0ccae6515b9d151984ec52/crates/desktop/src/assets/agent
Copyright (c) 2026 akarachen.

CodeArts Agent uses the Huawei Cloud mark and Cortex Code uses the Snowflake
mark, both from @lobehub/icons-static-svg 1.95.1 (Lobe Icons, MIT, Copyright
(c) 2023 LobeHub).

The remaining marks were taken from each product's own published artwork and
reduced to a single color; brand marks are used only to identify the product:
- AdaL: https://sylph.ai/adal-icon-pink.svg
- AiderDesk: hotovo/aider-desk-connector-intellij-plugin
  src/main/resources/META-INF/widgetIcon.svg at commit
  5c232b1004ff3cafe010849db0a313a0a9be3ea8 (Apache-2.0)
- Codemaker: traced as a vector silhouette from the CodeMaker logo bundled in
  y3-editor/y3-helper resources/webview_source_code/src/assets/codemaker-logo.png
  at commit 58c7dd7f4269c8c45435db79f6d25a4db0aa3d28
- Continue: continuedev/continue docs/logo/light.svg (Apache-2.0)
- Crush: redrawn as vector pixels from charmbracelet/crush
  internal/ui/notification/crush-icon-solo.png
- Deep Agents: langchain-ai/deepagents .github/images/logo-light.svg (MIT)
- Dexto: truffle-ai/dexto docs/static/img/dexto/dexto_logo_icon.svg
- Firebender: https://firebender.com/icon.svg
- ForgeCode: https://forgecode.dev/images/favicon-light.svg
- IBM Bob: https://bob.ibm.com/icon.svg
- iFlow CLI: sst/models.dev providers/iflowcn/logo.svg at commit
  d79178d498e9d0f3c4f67bc99a3842030fedca2b (MIT)
- MCPJam: MCPJam/inspector mcpjam-inspector/client/public/mcp_jam.svg
- Mux: coder/mux docs/favicon.svg
- Neovate: https://neovate.dev/favicon.svg
- Pochi: TabbyML/pochi packages/vscode/assets/icons/pochi-logo.svg (Apache-2.0)
- Rovo Dev: the Rovo Dev wordmark on https://www.atlassian.com/software/rovo-dev
- Code Studio: Syncfusion's code-studio-logo-v3.svg on
  https://www.syncfusion.com/code-studio/
- Tabnine CLI: codota/tabnine-vscode logo.svg (MIT)
Tile logos keep their glyph as a cut-out so the mark stays one color.

Each SVG was converted to a vector PDF with rsvg-convert --format pdf and
included as a template image so macOS supplies its foreground color.
