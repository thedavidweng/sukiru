Agent logo artwork

The agent logos in AgentIcons.xcassets identify compatible tools. Product names
and brand marks remain the property of their respective owners.

Amp, Antigravity, Claude Code, Codex, Cursor, Droid, Gemini CLI, GitHub
Copilot, Hermes Agent, OpenClaw, OpenCode, Pi, and Trae were converted from
Kitter's provider SVGs at commit 7de9372a8b691c8dffed6e9102d2c1c53b0e46b2:
https://github.com/what1f/kitter/tree/7de9372a8b691c8dffed6e9102d2c1c53b0e46b2/assets/icons
Kitter attributes these provider icons to Lobe Icons under MIT.
Copyright (c) 2023 LobeHub.

Augment, Cline, Kilo Code, Kimi Code CLI, Kiro CLI, Mistral Vibe, Roo Code,
Warp, Windsurf, and Zed were converted from aghub's agent SVGs at commit
61a7ee799a035cd5eb0ccae6515b9d151984ec52:
https://github.com/AkaraChen/aghub/tree/61a7ee799a035cd5eb0ccae6515b9d151984ec52/crates/desktop/src/assets/agent
Copyright (c) 2026 akarachen.

Each SVG was converted to a vector PDF with rsvg-convert --format pdf and
included as a template image so macOS supplies its foreground color.
